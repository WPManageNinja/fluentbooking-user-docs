# Booking Summary Report Email

The **Booking Summary** feature lets you receive regular booking reports by email. You can choose how often you want to receive the summary based on your preferred schedule.

## How to Configure Booking Summary

To set the **Booking Summary**, follow these simple steps:

### Open Global Settings

Navigate to the **Settings** icon from the FluentBooking dashboard top right side, then select the **General** tab from the left sidebar. This will take you to the **General Settings** page for FluentBooking, where you can configure your general settings for bookings.

### Summary Email Options

On the **General Settings** page, you'll find the following options:

- **Admin Email:** This is the email address for administrative notifications. All admin-targeted emails will go there; the default shortcode will fetch the admin email; you can also use other emails.

- **Summary Email:** Check the **Enable Booking Summary Notification** box to receive a summary email of your bookings. 

Once enabled, choose how often you want to receive these emails from the **Email Frequency?** dropdown.
