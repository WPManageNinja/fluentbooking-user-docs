# Create a Booking Event

Creating a new event in FluentBooking is the foundation of your scheduling system. This feature allows you to define exactly how, where, and for how long your meetings will occur, whether they are simple one-on-one sessions or group events. 

In this guide, we'll provide you with step-by-step instructions to create new bookings. Let's get started!


## Creating New Events


::: tip Important
Before creating a new event, make sure you've already created a [host](/how-to-create-a-new-host). You need at least one host to set up a booking event.
:::


To create a new event, go to the **Calendars** section from the top navigation bar in your FluentBooking dashboard. Click on the **New Event Type** button located next to the **Host Section**.


![Create a New Event](/images/host-events/how-to-create-new-events/create-event-scaled.webp)


## Choose Events Type


A pop-up will appear, giving you the choice between a **One-to-One** meeting or a **Group** meeting. Select your preferred meeting type.


![Choose Event Type](/images/host-events/how-to-create-new-events/choose-event-type-scaled.webp)


## Events Details


Here, you have to give the information about your booking event in the following fields


 * **A. Event Name:** Enter a suitable title here. This will show on your booking page.
 * **B. Description:** Add a short description of this event.
 * **C. Meeting Duration:** Choose how long your meeting will be.
 * **D. Location:** Choose where the meeting will take place (e.g., Zoom, Google Meet, Phone Call). You can add multiple location options by clicking on the **+ Add another location option** button. If the list of location choices fails to load, click **Retry** to reload it without refreshing the page.

After that, click on the **Continue** button to save it.

![Event Details](/images/host-events/how-to-create-new-events/event-details-2-scaled.webp)

## Search and Filter your Calendars

FluentBooking provides search, filter, and view options directly on your Calendars page, allowing you to locate specific events and streamline your workflow quickly.

### Switching Between List View and Grid View

By default, the **Calendars** page shows each host's event types in a **List View**, with the duration, meeting type, and location on a single row. To see your event types as cards instead, click the **Grid View** icon next to the search bar. Click the **List View** icon to switch back.

Your own calendar is always listed first and carries a **You** badge, so you can find it quickly on sites with many hosts.

![Calendars page in List View](/images/host-events/how-to-create-new-events/calendars-list-view.webp)

![Calendars page in Grid View](/images/host-events/how-to-create-new-events/calendars-grid-view.webp)

### Searching for a Specific Calendar

First, navigate to the **Calendars** section from your main FluentBooking dashboard. Locate the **Search calendars or event types** field at the top right corner of the page. **Type** the name of a calendar or an event type you are looking for, then press **Enter**. The list updates to display only the matching results.

Event types that have bookings coming up show an **Upcoming** count next to their name, such as **Upcoming: 1**, so you can see which events are in use at a glance.

![Searching calendars and event types](/images/host-events/how-to-create-new-events/calendars-search-upcoming-count.webp)

### Filtering Calendars by Type

From the **Calendars** page, use the tabs next to the search field to choose the type of calendar you wish to view. Your options include:

- **All:** Displays every calendar and event type you have created.
- **Hosts:** Shows standard one-on-one booking calendars associated with a single host.
- **Teams:** Filters for events that involve multiple hosts, such as round-robin or collective bookings.
- **One-off:** Displays single, non-recurring events.

The page updates right away and only shows calendars of the selected type.

![Calendar type tabs](/images/host-events/how-to-create-new-events/calendars-fluentbooking-scaled.webp)

## Quick Actions for Event Types

Every event type row has two quick actions on the right side, so you do not need to open the event first.

### Share an Event Type

Click the **Share** icon to open the share window for that event. It has tabs for **Shortcode**, **Landing Page**, **Add to Block**, **Generate Link**, and **Embed**, so you can copy whichever one you need.

![Share window for an event type](/images/host-events/how-to-create-new-events/event-type-share-action.webp)

### Edit, Turn Off, Clone, or Delete

Click the **three-dot icon** next to the **Share** icon to open the action menu. From here you can:

- **Edit:** Open the event to change its settings.
- **Turn Off:** Stop taking new bookings for the event. The option changes to **Turn On** once the event is off.
- **Clone:** Create a copy of the event.
- **Delete:** Remove the event permanently.

![Event type action menu](/images/host-events/how-to-create-new-events/event-type-more-actions.webp)

You can now efficiently find and manage your booking calendars using search, filter, and quick actions.
